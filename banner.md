# This prompt will help you generate Linkedin banner.

``` bash
Act as a designer and design a linkedin banner.  I have uploaded my  linkedin resume in a pdf format.
Analyze the pdf and make a banner according to the information provided in the pdf.
Remember No flashy colors , no text on the left side of the page. Make sure that the banner stand out.
Do not use any pic of a person . Make sure to use the LinkedIn’s banner size 1584×396 pixels.      
```
If you have any references you can combine both prompts

``` bash
With the pdf I also uploaded a few design reference. Analyze those design and then use the most insteresting part in
the banner. Do not copy the whole design.
```

If you have your own color then combine this also

``` bash
color 1 and color 2. Use only these color I provided and if necessary you are allow to use white or
black for text but if necessary.
```

If you don't want to overload the image with info

``` bash
Do not overload the design with information. Use white spaces. Use only the information  recuriter is interested in.
```

### Instruction 

Go to your LinkedIn profile on a desktop browser, click the Resources (or More) button in your intro section, and select Save to Pdf
